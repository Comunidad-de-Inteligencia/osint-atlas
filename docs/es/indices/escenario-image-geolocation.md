# Verificar una imagen y su ubicación

Contrastar una imagen con mapas, ortofotos, tiempo y otras señales abiertas.

## 🌐 Global

- [CelesTrak](../geoint/global-celestrak.md) — Consultar elementos orbitales públicos para estimar dónde está un satélite, no qué imagen toma.
- [Copernicus Data Space Ecosystem](../geoint/eu-copernicus.md) — Consultar escenas Sentinel. El navegador sirve para mirar una escena. El Data Space es el acceso a los productos.
- [Copernicus Emergency Management Service](../emergencias/eu-erascc-emergency-mapping.md) — Consultar cartografía y activaciones de respuesta a desastres.
- [Copernicus Marine](../geoint/eu-copernicus-marine.md) — Consultar productos marinos de Copernicus, como corrientes, temperatura o nivel del mar.
- [ESA SNAP](../geoint/global-esa-snap.md) — Descargar el programa de escritorio SNAP para abrir y revisar productos Sentinel en el equipo de quien consulta.
- [EUMETView](../geoint/eu-eumetview.md) — Ver imágenes meteorológicas de EUMETSAT para seguir nubes, tormentas o humo a escala amplia.
- [God's Eye View](../geoint/global-gods-eye-view.md) — Consultar un visor experimental que reúne fuentes públicas en un globo. No es una herramienta de este repositorio.
- [NASA FIRMS](../geoint/global-nasa-firms.md) — Consultar detecciones de fuego activo publicadas por NASA FIRMS como primer vistazo.
- [NASA Worldview](../geoint/global-nasa-worldview.md) — Explorar capas de observación de la Tierra de NASA, con fecha, para comparar una escena amplia.
- [OpenSky Network](../geoint/global-opensky.md) — Consultar trayectorias públicas de aviación recibidas por la red OpenSky, cuando el servicio responde.
- [OpenStreetMap](../geoint/global-osm.md) — Consultar cartografía colaborativa y objetos geográficos.
- [Overpass Turbo](../geoint/global-overpass.md) — Consultar objetos de OpenStreetMap con una pregunta geográfica, sin tratar el resultado como mapa oficial.
- [USGS Landsat](../geoint/global-usgs-landsat.md) — Orientarse en la misión Landsat y llegar a sus escenas ópticas históricas y recientes.
