# Copernicus Marine

## Para qué sirve

Consultar productos marinos de Copernicus, como corrientes, temperatura o nivel del mar.

## Qué necesitas

zona marina, fecha, variable

Acceso: **desconocido**. Coste: **Desconocido; consultar el servicio concreto.**.
Idiomas observados: **desconocido**.

Cobertura declarada: 🇪🇺 Unión Europea, 🌐 Global. Consulta el estado de revisión antes de darla por validada.

## Cómo utilizarla

Abre la [página responsable de Copernicus Marine](https://marine.copernicus.eu/).

1. Elige la variable y la fecha en el catálogo del servicio.
2. Conserva el nombre del producto.
3. Si falta la hora, no supongas que el mapa es actual.

## Ejemplo ficticio

Se mira una zona de mar ficticia, sin nombre de buque, para ver si hay un producto de temperatura fechado.

1. Anota variable, fecha y zona.
2. No cruces el dato con un viaje real ni con personas.

**Resultado esperado:** Queda escrito qué producto se vio y qué no cubre.

## Cómo interpretar el resultado

Un campo marino es un producto del servicio. No es la foto de un barco ni un parte de puerto.

## Limitaciones y alternativas

EU marca el servicio europeo. GLOBAL se conserva porque el océano se consulta desde otros lugares; si se quitara, dejaría de aparecer fuera de la Unión. La latencia y la licencia de cada producto siguen sin contrastar. No sustituye el aviso de un puerto.

Resultados que puede ofrecer: mapas o series marinas, metadatos del producto.

También se agrupa en: medio-ambiente. El archivo no se copia.
