# Seguridad

No publiques secretos, datos personales ni contenido ilegal en una incidencia. Un fallo del código se comunica en privado a quien administra el repositorio. No abras una incidencia pública con el detalle de una vulnerabilidad.

El mismo aviso, en inglés, está en [security](https://comunidad-de-inteligencia.github.io/osint-atlas/en/security/).

Este catálogo no recibe denuncias y no envía alertas. Si hay un peligro inmediato, acude al servicio oficial de emergencias de tu territorio. El [procedimiento de emergencia](procedimientos/emergencia-inmediata.md) está antes que esta página.

El conector Model Context Protocol (MCP) es de consulta. No envía reportes, no vigila canales y no decide que se ha cometido un delito.
