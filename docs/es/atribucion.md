# Atribución y procedencia

OSINT Atlas está inspirado en [OSINT Brazuca](https://github.com/osintbrazuca/osint-brazuca), sobre todo en la mezcla de documentación práctica, taxonomía y datos estructurados. OSINT quiere decir Open Source Intelligence, inteligencia de fuentes abiertas. OSINT Brazuca se distribuye con licencia MIT, Massachusetts Institute of Technology.
