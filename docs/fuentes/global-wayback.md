# Internet Archive Wayback Machine

> **Para qué sirve:** Consultar capturas históricas de páginas públicas.

## Antes de empezar

Necesitas: URL, fecha.

Acceso: **open**. Coste: **gratis o no indicado**. Idiomas: **es**.

Cobertura: **GLOBAL**.

## Cómo utilizarla

1. Abrir la captura y documentar URL original, fecha de captura y elementos ausentes.
2. Abre la [fuente principal](https://web.archive.org/) y registra la fecha de consulta.
3. Conserva como resultado: capturas archivadas.
