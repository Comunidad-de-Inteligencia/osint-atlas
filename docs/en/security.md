# Security

Do not publish secrets, personal data, or illegal content in an issue. A fault in the code is reported in private to the people who administer the repository. Do not open a public issue with the detail of a vulnerability.

The same notice in Spanish is [seguridad](https://comunidad-de-inteligencia.github.io/osint-atlas/seguridad/).

This catalog does not receive reports and does not send alerts. If you are in immediate danger, contact the official emergency service where you are. The [emergency procedure](https://comunidad-de-inteligencia.github.io/osint-atlas/procedimientos/emergencia-inmediata/) comes before this page.

The Model Context Protocol (MCP) connector is read-only. It does not send reports, it does not watch channels, and it does not decide that an offense has been committed.
