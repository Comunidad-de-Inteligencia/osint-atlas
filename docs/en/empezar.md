# Start with OSINT Atlas

OSINT means Open Source Intelligence: looking things up with information a person can obtain lawfully. A hit in a search is a starting point. It still needs context and a check.

The catalog entries in this tour are in Spanish. The steps are the same if you read them with a translation beside you.

## A five-minute tour

1. Write one concrete question. A fictional example: “Which documents would tell two similarly named companies in Spain apart?”
2. Open the [procedure on companies](https://comunidad-de-inteligencia.github.io/osint-atlas/procedimientos/investigar-empresa/).
3. Open [Spain](https://comunidad-de-inteligencia.github.io/osint-atlas/indices/jurisdiccion-es/) and read what coverage is still missing.
4. Open one entry, such as the [Boletín Oficial del Registro Mercantil (BORME)](https://comunidad-de-inteligencia.github.io/osint-atlas/empresas/es-borme/), the Spanish companies gazette. Check what it is for, what it asks for, what it cannot say, and whether review is still pending.
5. Follow the fictional example on the entry. Do not expect to find an invented company. An empty result is still a way to learn how to write a query down.
6. Note what you would observe, the original reference, and what you still could not conclude.

## How to read an entry

**What it is for** bounds the question. **What you need** is the starting data. **How to use it** is the sequence. **Expected result** says what kind of document or fact you might get. It does not promise a match.

**Interpretation** separates what was seen from what was inferred. **Limits** stop conclusions the source does not allow. **References** name the organization or service that is responsible.

An unknown language does not mean Spanish. An unknown price does not mean free. A page that answers does not prove an editorial review.

The territory mark sits beside the name. The name is what is read aloud.

## If you need urgent help

Open the [emergency procedure](https://comunidad-de-inteligencia.github.io/osint-atlas/procedimientos/emergencia-inmediata/). In sensitive scenarios, the first action and the competent source come before the technical detail.

Assistance, passing on an indication, a platform report, a takedown request, and a formal complaint are different routes. The catalog does not carry any of them out.

## When coverage is missing

Read the gaps for that territory. A general source can be context. Do not carry contacts, rules, or requirements from one country to another. [Propose an improvement](contribuir.md) and name the responsible page and what still needs checking.
