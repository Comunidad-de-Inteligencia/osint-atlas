# Verificar información durante un desastre o una crisis

## Actuación prioritaria

Sigue las instrucciones de emergencias y autoridades locales. Los mapas y agregadores de este catálogo aportan contexto, pero no sustituyen órdenes de evacuación ni alertas oficiales.

## Procedimiento

1. Define el área y la ventana temporal exactas.
2. Comprueba alertas y recomendaciones del organismo competente.
3. Anota la hora de actualización y la zona cubierta.
4. Contrasta imágenes con cartografía, meteorología y comunicaciones oficiales.
5. Marca claramente previsiones, observaciones, estimaciones e información confirmada.
6. Evita difundir cifras o rutas que puedan entorpecer la respuesta.

## Ejemplo ficticio

Un mapa temprano estima un área afectada. Se cita como estimación inicial y se reemplaza en el informe cuando aparece una delimitación oficial posterior.

## Criterio de finalización

La información crítica tiene hora, territorio, fuente y estado; las versiones superadas quedan identificadas.
