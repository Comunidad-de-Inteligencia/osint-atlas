# Contrastar y documentar conclusiones

## Objetivo

Producir un resultado que otra persona pueda revisar sin repetir toda la investigación.

## Método

Clasifica cada elemento como:

- **Observación:** lo que muestra directamente una fuente.
- **Hecho corroborado:** observación confirmada por una fuente con autoridad adecuada.
- **Inferencia:** explicación razonada a partir de observaciones.
- **Hipótesis:** posibilidad todavía abierta.

## Procedimiento

1. Formula una pregunta concreta y un criterio de parada.
2. Registra URL, organismo, fecha de publicación y fecha de consulta.
3. Busca una fuente independiente para los puntos decisivos.
4. Anota contradicciones y datos ausentes.
5. Redacta las conclusiones con el nivel de certeza que permiten las pruebas.
6. Revisa privacidad, necesidad y posible daño antes de compartir.

## Ejemplo ficticio

Dos fuentes repiten una cifra procedente del mismo comunicado. Se cuentan como una procedencia, no como dos confirmaciones independientes.

## Criterio de finalización

Cada conclusión tiene evidencia cercana, las inferencias están marcadas y las limitaciones resultan visibles.
