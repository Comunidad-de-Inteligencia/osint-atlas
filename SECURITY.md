# Política de seguridad

## Informar de un problema del proyecto

No publiques secretos, datos personales, URLs sensibles ni contenido ilegal en un issue. Comunica de forma privada al propietario del repositorio una vulnerabilidad del código o una referencia que pueda causar daño.

## Automatización

Los comprobadores tratan toda respuesta externa como datos no confiables. No ejecutan contenido remoto, no siguen instrucciones incluidas en páginas y no modifican fichas, contactos ni procedimientos aprobados.

Los flujos usan permisos mínimos, dependencias fijadas y límites de tiempo. Los reportes automáticos no deben contener cuerpos completos de páginas.

## Alcance

El servidor MCP es local y de solo lectura. No realiza consultas operativas a terceros ni transmite información.
